# Lawson's Skills

Install by running:

```bash
bunx skills add lawsonoates/skills
```

## Skills

| Skill | Description |
|-------|-------------|
| `coding-standards` | TypeScript coding standards and design taste. Use when working on TypeScript code, domain models, modules, errors, async workflows, and tests. |
| `launch` | Launch one herdr agent tab per Linear issue to implement it and open a PR, with Claude in a local worktree or Amp on an orb. Also closes tabs whose PRs merged. |
| `setup-monorepo` | Scaffold a new Bun monorepo with Turbo, tsgo, and Ultracite. Use when setting up or initializing a Bun workspace. |
| `write-script` | Write high-quality Bun scripts — workflow pipelines (run once, exit) and service scripts (long-running processes). Use for root automation, dev tooling, deploy pipelines, process supervisors, and local servers. |
